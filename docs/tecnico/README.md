# Documentación técnica

Documentación técnica de la plataforma del piloto: requisitos, arquitectura, tecnologías y modelo de datos. Se escribe en Markdown junto al código, y los diagramas se hacen en Mermaid. Para entregas formales se exporta a PDF.

Estado: **en preparación** (semana 4 del plan, 12–18 nov 2026).

| Documento | Contenido |
|---|---|
| `requisitos.md` | Actores, casos de uso, requisitos funcionales y no funcionales con criterios de aceptación |
| `arquitectura.md` | Componentes, flujo de datos, tecnologías, integraciones externas, despliegue y operación |
| `modelo-de-datos.md` | Estructura del perfil de una persona y procedencia de cada campo |
| `seguridad-y-privacidad.md` | Manejo de claves, autorización del titular y aviso de privacidad |
| `decisiones/` | Registro de decisiones técnicas (ADR): un archivo por decisión, `NNNN-titulo.md` |

La gestión del proyecto (alcance, carta Gantt y notas de ideas) está en la carpeta compartida de Google Drive, no en este repositorio.
