# Registro de decisiones técnicas (ADR)

Cada decisión importante se guarda en un archivo `NNNN-titulo-breve.md` con estas secciones:

- **Estado:** propuesta, aceptada, reemplazada por NNNN
- **Contexto:** qué problema había
- **Decisión:** qué se eligió
- **Consecuencias:** qué se gana, qué se pierde y qué queda pendiente

Las decisiones no se borran. Si una cambia, se escribe una nueva que reemplaza a la anterior.
